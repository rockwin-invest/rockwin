# Equin Bank

A modern digital banking platform built with Node.js, Express, MongoDB, and vanilla HTML/CSS/JS.

## Features

- ✅ KYC-compliant signup (Name, ID, DOB, Phone)
- ✅ Secure login with JWT
- ✅ Password reset via OTP (SMS)
- ✅ Client dashboard with balance, transactions, insights
- ✅ Admin panel with user management, balance adjustments, SMS broadcast
- ✅ Audit logging for all admin actions
- ✅ Role-based permissions (Super Admin, Operations, Auditor, Support, Compliance)
- ✅ Bulk SMS integration (Africa's Talking)
- ✅ Mobile-first responsive design

## Tech Stack

- **Backend:** Node.js, Express, MongoDB, JWT
- **Frontend:** HTML5, CSS3 (custom), Vanilla JS
- **SMS:** Africa's Talking / Mobilesasa API
